FASTEST WAY TO GET RUNNING:

1. OPEN TERMINAL & RUN:
   cd d:\malikussaleh\joki\nexanews-app
   composer install

2. SETUP .env:
   cp .env.example .env
   php artisan key:generate

3. DATABASE (edit .env first if needed):
   php artisan migrate
   php artisan db:seed

4. STORAGE:
   php artisan storage:link

5. RUN SERVER:
   php artisan serve

6. OPEN BROWSER:
   http://localhost:8000

7. LOGIN AS ADMIN:
   Email: admin@nexanews.com
   Password: admin123456
